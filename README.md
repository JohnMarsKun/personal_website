# Personal Website

This project is a static website (`index.html` + CSS/JS), so it does not need a build step.

## Run locally

1. Open a terminal in this folder.
2. Start the local server:
   ```bash
   npm run dev
   ```
3. Open:
   `http://localhost:3000`
